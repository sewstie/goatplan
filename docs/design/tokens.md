# Design tokens

Every value comes from the Figma file (`GoatPlan`, section "Prototype v1."), from its variables and from the styles used in the 23 frames. The left column is the **CSS variable to use in code**. The Figma name is there so you can find the value in Figma.

Things to know first:

- **Font.** Figma uses **Inter**. The project rule (CLAUDE.md) is **DM Sans**, so use DM Sans with the same sizes and weights. DM Sans is a variable font, so in-between weights like 570 and 650 work. Text will run a little wider than in the PNGs.
- **Sizes are Figma px at the 1680-wide frame.** Body text is small (9–11px). Use the values as they are, 1px = 1px.
- **The Figma variables were generated by an HTML import.** Many are layout leftovers, not tokens: `item spacing/1003_01`, `width/141_89`, `stroke weight/0_05` and the like. They're listed at the end as "don't use".
- **Not in Figma**: dark theme, focus style, hover and pressed styles for buttons and inputs, and hover borders for courses other than the peach one. Tokens added in code for these are marked **proposed, not in Figma yet** until they exist as Figma variables.
- Shadows are not Figma variables. They come from node effects and are listed below.
